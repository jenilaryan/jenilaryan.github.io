About Me

Embedded Firmware
Engineer

I am an Embedded Firmware Engineer passionate about developing reliable software for ARM Cortex-M microcontrollers. My interests include STM32, Embedded C, RTOS, device drivers, communication protocols (UART, SPI, I2C), and low-level embedded systems programming. I enjoy building hands-on projects that demonstrate practical firmware development skills.

STM32 UART
LED Command Parser

Developed a UART command parser on the STM32 NUCLEO-F446RE using Embedded C and the STM32 HAL library. The firmware receives serial commands over USART2, parses text commands, controls the onboard LED, echoes commands, and handles invalid inputs.
